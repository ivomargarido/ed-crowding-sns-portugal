# ED Crowding SNS Portugal

## Project overview

This project explores emergency department pressure in Portugal's National Health Service (SNS) using public data.

The goal is to understand how pressure in hospital emergency departments evolves over time and across institutions, using indicators such as emergency attendances, waiting times, triage priority and hospital admissions.

## Main research question

How does healthcare pressure evolve in SNS hospital emergency departments in Portugal, and which public indicators can be used to monitor patterns of crowding over time and across institutions?

## Project scope

This is Project 1 of a broader Health Data Science portfolio focused on emergency departments, waiting times, patient flow and hospital crowding.

Project 1 focuses on exploratory analysis and monitoring.

Predictive modelling, risk classification and dashboard development will be addressed in later projects.

## Data sources

Planned data sources:

- Portal da Transparência do SNS
- Atividade nos Cuidados Saúde Hospitalares — Monitorização Sazonal
- Atendimentos por Tipo de Urgência Hospitalar
- Atendimentos em Urgência Hospitalar por Triagem de Manchester

## Planned analysis

- Data quality assessment
- Temporal analysis of emergency attendances
- Analysis of waiting times between triage and first medical observation
- Relationship between volume and waiting times
- Analysis of admission rates after emergency episodes
- Analysis of triage priority distribution
- Comparison across institutions
- Exploratory pressure monitoring indicator
